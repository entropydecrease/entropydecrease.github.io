「Codex + ChatGPT Desktop + 网页」三者协同工作流

July 20, 2026
Categories: Tech
Tags: AI

ok,请分享你认为目前效率最高的 「Codex + ChatGPT Desktop + 网页」三者协同工作流

我自己会把三者定位得非常明确：

Codex = 工程师（执行）

ChatGPT 网页 = 架构师（思考）

ChatGPT Desktop = 助手（即时）

很多人把它们混着用，结果就是：

  • Codex 上下文越来越大；
  • ChatGPT 聊天越来越乱；
  • 一个需求来回复制粘贴。

而我建议的是职责分离。

第一层：Codex 只负责「改代码」

这是最重要的一点。

很多人会把 Codex 当 ChatGPT 用：

PLAINTEXT 
解释一下这里为什么这样设计

顺便介绍一下这个算法

给我比较一下 xx 和 yy

未来怎么优化
解释一下这里为什么这样设计 顺便介绍一下这个算法 给我比较一下 xx 和 yy 未来怎么优化

这样 Context 很快就爆了。

我的建议是：

Codex 里面永远只讨论"当前仓库"。

例如：

PLAINTEXT 
实现 Feature X

修复 Bug Y

重构 module A

运行测试

修 CI

review diff
实现 Feature X 修复 Bug Y 重构 module A 运行测试 修 CI review diff

不要讨论：

  • 行业知识
  • 大模型知识
  • Linux
  • Rust为什么这样设计
  • Kubernetes

这些全部放 ChatGPT。
